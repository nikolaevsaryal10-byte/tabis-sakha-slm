> Данный релиз является **чисто исследовательским научным экспериментом** в рамках Всероссийской программы «Шаг в будущее».  
> * **Перевод с якутского на русский (sah ➔ ru):** Модель справляется хорошо, корректно распознает конструкции и точно передает смысл исходных текстов.  
> * **Перевод с русского на якутский (ru ➔ sah) и свободный диалог:** Модель может работать некорректно («тупить») и генерировать артефакты (повторы токенов, псевдо-слова, грамматические сбои). Это вызвано фундаментальной причиной: базовый токенизатор Qwen не имеет якутских букв `Ҕ, Ҥ, Ү` и дробит слова на байты ($F \approx 5.0 - 8.0$), а исходный параллельный датасет содержал OCR-шум и сдвиги строк.  
> * Данные выявленные проблемы легли в основу разрабатываемого пайплайна **«Табыс 1.1 / 2.0»** (с расширенным словарем и 50 000 чистыми диалогами).

## 📌 Описание проекта

**«Табыс» (Tabis)** — суверенная билингвальная малая языковая модель (Small Language Model, SLM), адаптированная для работы с малоресурсным якутским языком и русско-якутским переводом.

* **Базовые архитектуры:** Модели построены на основе открытых фундаментальных архитектур **Qwen 3.5 4B** и **Qwen 3.5 0.9B (0.8B)**.
* **Обучающий корпус (Датасет):** Для адаптации и настройки перевода использовался открытый корпус параллельных русско-якутских предложений [ailabykt/sakha-russian-parallel](https://huggingface.co/datasets/ailabykt/sakha-russian-parallel).
* **Аппаратная база и метод:** Модели дообучены локально на потребительском GPU (NVIDIA GeForce RTX 5060, 8 ГБ VRAM) с применением эффективной квантованной адаптации QLoRA 4-bit.

Квантованные модели в формате **GGUF (Q4_K_M)** оптимизированы для запуска на любых персональных компьютерах и ноутбуках без подключения к интернету и без использования сторонних облачных API.

## 🚀 Как запустить модель локально

### Вариант 1. В программе LM Studio (Рекомендуется)
1. Установите [LM Studio](https://lmstudio.ai/).
2. Скачайте файл `tabis1.0_4b.gguf`.
3. Поместите его в папку моделей LM Studio (`~/.cache/lm-studio/models/...`).
4. В поле **System Prompt** укажите:
   ```text
   Ты — «Табыс» (tabis1.0), интеллектуальный ассистент и переводчик якутского языка. Твой автор и разработчик — Николаев Сарыал Павлович, ученик 11 класса МБОУ «Намская улусная гимназия им. Н.С. Охлопкова». Отвечай доброжелательно, грамотно и точно.
   ```
5. Рекомендуемые параметры: **Temperature = 0.2**, **Repetition Penalty = 1.15**.

### Вариант 2. Через llama.cpp (Консоль)
```bash
./llama-cli -m tabis1.0_4b.gguf -p "Переведи на якутский: Сегодня прекрасный солнечный день." -ngl 99 -c 2048 --temp 0.2
```
